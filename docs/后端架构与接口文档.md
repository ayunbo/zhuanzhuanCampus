# 后端架构与接口文档

## 后端架构检查结果

- 项目采用 Maven 多模块 Spring Boot 架构，核心模块包括 `zhuanzhuan-server`、`zhuanzhuan-account-platform`、`zhuanzhuan-goods-platform`、`zhuanzhuan-trade-platform`、`zhuanzhuan-review-platform`、`zhuanzhuan-collect-platform`、`zhuanzhuan-history--platform`、`zhuanzhuan-common`、`zhuanzhuan-pojo`。
- `zhuanzhuan-server` 负责启动、WebMvc 配置、JWT 拦截器、OSS 上传入口、Swagger。
- `zhuanzhuan-common` 负责统一返回体 `Result<T>`、分页对象 `PageResult`、常量、上下文、工具类。
- `zhuanzhuan-pojo` 负责 DTO / VO / Entity。
- 账户、商品、订单支付、评价、收藏、浏览历史分别拆分在独立业务模块中。
- 鉴权方式为 JWT，管理员和用户请求头名称都为 `token`。
- 管理端拦截范围：`/admin/**`，排除 `/admin/login`。
- 用户端拦截范围：`/user/**`，排除 `/user/register`、`/user/login`、`/user/login/buyer`、`/user/login/seller`、`/user/category/**`、`/user/goods/**`、`/user/review/goods/**`。

## 通用返回结构

| 字段 | 说明 | 类型 |
| --- | --- | --- |
| code | 状态码，1=成功，0=失败 | integer(int32) |
| msg | 提示消息，成功一般为 null | string |
| data | 业务数据，按接口不同而变化 | object / array / string / integer / null |

## 1. 用户与权限模块（JWT）

模块说明：这个模块负责买家/卖家共用的账号体系：用户注册登录、JWT 发放与校验、接口权限控制、用户个人资料维护（昵称、头像、联系方式、校区等），同时承载用户提交卖家认证申请的入口。

实现说明：当前代码已实现注册登录、个人资料维护、卖家认证申请与结果查询；JWT 校验通过全局拦截器完成。
