# 管理员用户管理接口设计

## 复用说明
- 复用 `UserMapper` 现有能力：`insert`、`getById`、`getByStudentNo`、`getByPhone`、`countByPhoneExcludeId`、`updateByIdSelective`、`deleteById`。
- 新增最小能力：`pageQueryAdmin`（管理员分页查用户）。
- 业务复用：删除用户前复用 `SellerAuthMapper.getLatestByUserId` 校验“待审核认证不能删除”。

## 接口列表（Admin）

### 1. 新增用户
- `POST /admin/user`
- 入参：`AdminUserSaveDTO`（`id` 不传）
- 核心校验：
  - `studentNo`、`password` 必填
  - `studentNo` 唯一
  - `phone`（传入时）唯一
  - `role/status` 合法（默认 `role=1`、`status=1`）

### 2. 分页查询用户
- `GET /admin/user/page`
- 入参：`AdminUserPageQueryDTO`
- 筛选字段：`studentNo`、`name`、`phone`、`role`、`status`
- 返回：`PageResult<UserProfileVO>`

### 3. 查询用户详情
- `GET /admin/user/{id}`
- 返回：`UserProfileVO`

### 4. 修改用户
- `PUT /admin/user`
- 入参：`AdminUserSaveDTO`（`id` 必传）
- 核心校验：
  - `id` 必填
  - 目标用户必须存在
  - 至少传一个更新字段
  - `studentNo`（改动时）唯一
  - `phone`（传入时）唯一
  - `role/status` 合法

### 5. 删除用户
- `DELETE /admin/user/{id}`
- 核心校验：
  - 用户存在
  - 若存在待审核卖家认证申请，不允许删除
